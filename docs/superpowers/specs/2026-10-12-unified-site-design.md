# God-here unified review site

User intent: put the character workbook, original audiovisual source, region/time-linked annotations, all retained project work and both review sites into one navigable main site; remove chaotic controls and repair failed interactions.

The main entry point becomes Review, not a gate in front of one experiment. Five task destinations are Review, Compare, Compose, Library, Project. Review reuses the exact supplied 174-event annotation engine and immutable workbook/media; existing annotation JSON and browser recovery key remain valid. Compare/Compose mount existing apps on the same origin with one active playback owner. The source monitor, timeline, waveform and note form stay synchronized. Legacy tools retain their native clocks; only verified mappings enable “Note this moment”. No universal timestamp conversion is assumed.

Preserve legacy paths and sources; retain the former main experience as experience.html. Do not delete archives or replace an unavailable artifact with a new reconstruction. Library merges every frozen identity and addendum and makes availability explicit. Project reports source coverage and open gaps independently of media decode and artistic acceptance. Local notes and audience responses are never published by the build.

Migration boundaries: main-site publishing tools are unavailable in this session. The secondary evaluation site returns HTTP 401. The exact saved Study05 application was recovered and can be mounted in the owner-only preview; its current live user state was not retrieved. Never claim it is publicly migrated or fully audited. The deliverable is a tested deployment overlay and repository change, with these gates open. Do not replace the main site with a new host. Owner-only recovered applications remain in the owner integration bundle, never the public source repository. Font files are never distributed. The deployment manifest requires protected access for recovered players and project snapshots. The bounded live capture does not certify all historical sessions.

Interface: quiet neutral surfaces, strong content hierarchy, visible focus, 44px primary touch targets, persistent task navigation, progressive disclosure for reference documents and export controls, a compact timeline by default, explicit loading/error/retry states, and no silent dead buttons. Mobile stacks the monitor before the inspector and uses horizontally scrollable navigation/timeline without whole-page overflow.

Acceptance: source/workbook hashes unchanged; all 174 records retained; old JSON round trip and conflicting edits preserved; all 3213 catalog identities retained without duplicate hashes; privileged/unavailable media not given fictitious play links; app changes pause earlier audio; backward-compatible deep links; actual playback, seek, annotation, export/import, responsive and failure-path tests. Existing repository suite must run and any failures be reported by name.
