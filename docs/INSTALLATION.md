# Installation readiness

No actual venue, loudspeaker set, or display geometry has been supplied. This is an operator protocol and configuration template, not a claim of physical calibration.

Start with the linear workprint on one display and stereo playback. Once the repair is accepted, extend the shared dry dialogue and independently routed effect returns. Current returns are mixture-based estimates; five original speaker stems are unavailable.

1. Record venue dimensions, intended listening area, projector/display placement, audio-interface model, speaker coordinates, and routing.
2. Verify the source workprint and stem checksums before loading. Start every channel from the same transport.
3. Measure output latency and compensate channel-to-channel offsets at the intended listening position. Verify intelligibility across the audience area using the scene, not a test tone alone.
4. Set playback level in the room. Record actual levels and microphone/meter method; do not substitute the online LUFS target for a physical listening-level decision.
5. Test reflections, interference, leakage, drift, and behavior during repeated playback. Check whether independent spatial returns mask quiet dialogue.
6. Run pause, restart, power/interruption, and recovery trials. Keep the known source-length linear edition available as fallback.
7. Save the equipment/routing map, compensation, level settings, accepted edition hashes, and observed limitations together.

Operator recovery: pause playback, disable interactive attention, reset score/time to zero, select the accepted linear fallback, verify the dry dialogue bus, then resume. Never resume a partial set of independently clocked character players.

GHERE-038 activates only when a real installation target is selected. Technical and artistic acceptance in one room must not be generalized to an untested room.
