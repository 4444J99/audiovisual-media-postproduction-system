What the comparison contains
A–C retain the original source timing. D–E give the selected movement 0.8 additional seconds, introduce two tracked reframings, and animate independently timed words.
Switching versions preserves the corresponding source moment rather than the same output second. Playback does not mark dialogue or audio restoration as accepted.
Close-ups are resampled from the 720p recording with restrained sharpening. 1080p delivery is not proof of recovered facial or object detail. Tracking uses manually seeded image features, not identity recognition. Text is authored graphics, not verified captions.


Render an exported change
python -m amp.direction \
  --source /path/to/original.mp4 \
  --audio /path/to/full-source-candidate.wav \
  --recipe direction-export.json \
  --fields projects/god-here/direction-field-score.json \
  --font /path/to/installed-font.ttf \
  --variant directed \
  --output /path/to/new-revision.mp4
The full-source-timed audio is required. The exported JSON is consumed directly by the renderer. Unknown fields, invented acceptance states, invalid geometry, and unsupported timing are rejected offline.
